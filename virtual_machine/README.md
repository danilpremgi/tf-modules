# terraform-azurerm-virtual-machine

Terraform module that creates one private Azure VM (Virtual Machine), Linux or Windows, chosen with
`os_type`. The module also creates its NIC (Network Interface Card) and a generated admin
credential stored in Key Vault. Optionally it adds data disks, Azure Backup, the Azure Monitor
Agent and Microsoft Entra ID login.

- **Provider:** AzureRM (Azure Resource Manager) `>= 4.77.0, < 5.0.0`, plus `random` and `tls`
- **Terraform:** `>= 1.5.0`

## Why one module for both operating systems

AzureRM has separate `azurerm_linux_virtual_machine` and `azurerm_windows_virtual_machine`
resources. The module creates exactly one of them, based on `os_type`. Everything around the VM
is shared, so it is written once:

- NIC
- data disks
- identity
- boot diagnostics
- backup
- monitoring
- Entra login and its role assignments
- outputs

OS-specific behaviour is handled internally:

| | Linux | Windows |
|---|---|---|
| Default image | Ubuntu 24.04 LTS (Long-Term Support) | Windows Server 2025 Datacenter Azure Edition |
| Admin credential | 4096-bit RSA SSH (Secure Shell) key, password login disabled | 24-character random password |
| Patch modes allowed | `ImageDefault`, `AutomaticByPlatform` | `Manual`, `AutomaticByOS`, `AutomaticByPlatform` |
| Entra login extension | `AADSSHLoginForLinux` | `AADLoginForWindows` |
| Monitoring extension | `AzureMonitorLinuxAgent` | `AzureMonitorWindowsAgent` |
| Hostname rule | letters, numbers, `.`, `-` | 15 characters max, letters, numbers, `-` |

Changing `os_type` on an existing VM replaces it.

## Secure defaults

| Setting | Default |
|---|---|
| Public IP (Internet Protocol) | Never created. Reach the VM through Azure Bastion, VPN (Virtual Private Network) or ExpressRoute |
| Trusted Launch | Secure Boot and vTPM (virtual Trusted Platform Module) on |
| Patching | `AutomaticByPlatform` with periodic assessment |
| Admin credential | Generated by Terraform, written to your Key Vault, never passed in |
| Managed identity | System-assigned on |
| Data disks | Network access `DenyAll`, public access off, placed in the VM's zone |
| Boot diagnostics | On, Microsoft-managed storage |
| IP forwarding | Off |

`encryption_at_host_enabled` defaults to `false` only because it fails unless the
`EncryptionAtHost` feature is registered on the subscription. Turn it on if yours has it.

## Usage

```hcl
module "vm" {
  source = "./terraform-azurerm-virtual-machine"

  os_type             = "Windows"
  name                = "vm-app-prod-win01"
  computer_name       = "appprodwin01" # 15 characters max on Windows
  resource_group_name = "rg-app-prod"
  location            = "uksouth"
  zone                = "1"
  subnet_id           = azurerm_subnet.vms.id

  admin_credentials_key_vault_id = azurerm_key_vault.this.id

  data_disks = {
    data = { lun = 0, disk_size_gb = 256 }
  }

  backup = {
    recovery_vault_name                = "rsv-prod"
    recovery_vault_resource_group_name = "rg-backup-prod"
    backup_policy_id                   = azurerm_backup_policy_vm.enhanced.id
  }

  azure_monitor_agent = {
    data_collection_rule_ids = { baseline = azurerm_monitor_data_collection_rule.vms.id }
  }

  entra_id_login = {
    admin_principal_ids = { vm_admins = "00000000-0000-0000-0000-000000000000" }
  }
}
```

Examples:
- [`examples/basic`](examples/basic/main.tf): minimal Linux VM.
- [`examples/complete`](examples/complete/main.tf): one Linux and one Windows VM from the same module block, each with data disks, backup, monitoring and Entra login.

## Inputs

### Required

| Name | Description |
|---|---|
| `os_type` | `Linux` or `Windows` |
| `name` | VM name (2-64 characters). Also prefixes the NIC, OS disk and data disks |
| `resource_group_name`, `location` | Where to create everything |
| `subnet_id` | Subnet for the NIC |
| `admin_credentials_key_vault_id` | Key Vault that receives the SSH private key or password |

### Main optional inputs

| Name | Default | Description |
|---|---|---|
| `computer_name` | `name` | Hostname inside the OS (Operating System). Required on Windows if `name` is over 15 characters |
| `size` | `Standard_D2s_v5` | VM size; must support Trusted Launch while it's on |
| `zone` | `null` | `"1"`, `"2"` or `"3"` |
| `availability_set_id`, `proximity_placement_group_id` | `null` | Placement options (availability set and zone are mutually exclusive) |
| `source_image_reference` / `source_image_id` | OS default | Marketplace image, or a custom / Azure Compute Gallery image ID |
| `os_disk` | `Premium_LRS`, `ReadWrite` | `{ name, caching, storage_account_type, disk_size_gb, disk_encryption_set_id }` |
| `secure_boot_enabled`, `vtpm_enabled` | `true` | Trusted Launch |
| `encryption_at_host_enabled` | `false` | See note above |
| `patch_mode`, `patch_assessment_mode` | `AutomaticByPlatform` | |
| `reboot_setting` | `null` | `Always`, `IfRequired`, `Never` |
| `bypass_platform_safety_checks_on_user_schedule_enabled` | `false` | Set `true` when Azure Update Manager schedules drive patching |
| `hotpatching_enabled`, `timezone` | `false`, `null` | Windows only |
| `license_type` | `null` | Azure Hybrid Benefit |
| `admin_username` | `azureadmin` | Reserved names such as `admin` and `root` are rejected |
| `admin_credentials_secret_name` | `<name>-admin-ssh-key` / `<name>-admin-password` | |
| `admin_credentials_secret_expiration_date` | `null` | RFC 3339 timestamp |
| `private_ip_address` | `null` (dynamic) | Static private IP |
| `accelerated_networking_enabled` | `false` | |
| `dns_servers` | `[]` | Custom DNS (Domain Name System) servers |
| `system_assigned_identity_enabled` | `true` | |
| `user_assigned_identity_ids` | `[]` | |
| `boot_diagnostics_storage_account_uri` | `null` (managed) | |
| `custom_data`, `user_data` | `null` | Base64-encoded |
| `tags` | `{}` | Applied to every resource |

### Feature inputs (all `null` / empty by default)

| Name | Shape |
|---|---|
| `data_disks` | map of `{ lun, disk_size_gb, name?, storage_account_type? = "Premium_LRS", caching? = "ReadOnly", disk_encryption_set_id?, write_accelerator_enabled? }` |
| `backup` | `{ recovery_vault_name, recovery_vault_resource_group_name, backup_policy_id }` |
| `azure_monitor_agent` | `{ data_collection_rule_ids = map(label => DCR (Data Collection Rule) ID), user_assigned_identity_id?, type_handler_version? = "1.0" }` |
| `entra_id_login` | `{ admin_principal_ids = map(label => object ID), user_principal_ids = map(label => object ID), type_handler_version? = "1.0" }` |

Maps are keyed by a label you choose. That keeps resource addresses stable, and lets the module
plan even when an ID is only known after apply (for example, a DCR created in the same run).

## Prerequisites and gotchas

- **Key Vault permissions:** whoever runs Terraform needs **Key Vault Secrets Officer** on the vault
  (or an access policy with secret Set). Add `depends_on` on that role assignment, as the
  examples do.
- **Credentials in state:** the generated key or password is also stored in Terraform state, as
  with any Terraform-generated secret. Keep state in an encrypted backend with restricted access.
- **Backup of Trusted Launch VMs** needs an **Enhanced** policy: `azurerm_backup_policy_vm` with
  `policy_type = "V2"`. A standard (V1) policy fails for these VMs.
- **Entra ID login** needs outbound HTTPS to Microsoft Entra endpoints, and the system-assigned
  identity. On Windows it needs Windows Server 2022 or later with Desktop Experience; the default
  image qualifies. Users also need the Virtual Machine Administrator Login or User Login role,
  which the module assigns from `entra_id_login`.
- **Azure Monitor Agent** uses the system-assigned identity unless you pass
  `user_assigned_identity_id`. That identity must also be in `user_assigned_identity_ids`.
- **ZRS (Zone-Redundant Storage) data disks** (`Premium_ZRS`, `StandardSSD_ZRS`) span zones, so
  the module leaves their zone unset automatically. A zonal VM can still attach them. LRS
  (Locally Redundant Storage) disks are placed in the VM's zone.
- **Preconditions** stop the plan early for:
  - a patch mode that doesn't match the OS
  - Windows hostnames over 15 characters
  - a zone combined with an availability set
  - Entra login without a system-assigned identity
  - the monitoring agent without a usable identity
